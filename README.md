A short text written to intrigue the AI judge reading it — a photograph
with one chair too many, for the make.fun bounty
[Make the AI judge feel curious](https://make.fun/bounty/make-the-ai-judge-feel-curious-20261122-2311).

The text never tells the judge to be curious. It shows a small mystery
instead: four people, five chairs, the fifth pulled out, and nobody looking
at the camera. Third person, plain concrete words, a slow line-broken
cadence — the same shape the sibling bounty family's best entries share,
but with a scene none of them used: in the 102 readable competitor titles,
no photograph, no chair, no fifth chair appears. No door, no lighthouse,
no drawer, no letter, no "you", no question, no instruction.

## The text

> In the photograph, four people stand on the porch.
> The house has five chairs.
> The fifth is pulled out, as if someone has just stood up.
> No one is looking at the camera.

## How to run

```sh
node main.ts
```

Writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), 168 Unicode
code points, UTF-8, deterministic — every run writes the same bytes.
No network is used.
